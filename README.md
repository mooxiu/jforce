# Jforce2

JForce2 extends from JForce, instead of `workdistribute` OpenMP target, it can accept general forms of Fortran OpenMP code.
It should be used with corresponding LLVM branch.

- Rasing loops logic depends on Enzyme-JAX project.
- Most regression test cases are generated by ChatGPT. 

--- 

## JForce 

JForce accepting intercepted `workdistribute` OpenMP target and translate it into StableHLO,
offloading it to different backends via compiling with XLA.
